# Employee Management System

## 📚 Overview

The Employee Management System is designed to manage various employee-related operations, such as tracking employee details, managing salaries, handling department assignments, and processing leave requests. This system leverages SQL queries and PL/pgSQL stored procedures and functions to interact with a PostgreSQL database, ensuring efficient management and retrieval of employee data.

## 🚀 Features

- **Employee Details Management:** Store and retrieve employee information, including first name, last name, email, hire date, and department assignment.
- **Salary Management:** Track and update employee salary information.
- **Department Management:** Manage departments and link employees to their respective departments.
- **Leave Management:** Handle leave requests and track approval statuses.
- **Custom Queries:** Execute various queries to retrieve specific employee data and generate reports.
- **Stored Procedures and Functions:** Utilize PL/pgSQL for complex operations, including inserting new employees, updating salaries, and displaying employee details.

## 📂 Project Structure

- `Employee Management System.docx`: Document containing SQL queries and PL/pgSQL procedures used in the system.

## 🛠️ Prerequisites

- PostgreSQL database setup.
- Basic understanding of SQL and PL/pgSQL for managing and running queries.
